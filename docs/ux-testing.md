# UX-тестирование по сценариям

Чек-лист ручной проверки для двух сценариев. Проходить в Chrome DevTools
(режим устройства, вьюпорты 360 / 390 / 768 px) и на реальном телефоне.

## Сценарий «ребёнок 5 лет» (режим 5–8)

1. Открыть главную — темы крупные, кнопки большие, текста мало.
2. Переключатель возраста оставить на «5–8».
3. Открыть «Алфавит» → игра «Слушай и выбирай»: звука пока нет → должна
   появляться подсказка с транскрипцией (не тишина).
4. Открыть «Цвета» → «Найди пары»: картинки (цветные кружки) крупные, легко
   тапать. Проверить, что неверная пара подсвечивается красным и «съедает»
   сердечко.
5. Проверить, что маскот реагирует (прыгает/качается + реплика).
6. Проверить, что при 0 сердечек показывается экран «Сердечки кончились».
7. После урока — модалка со звёздами и XP, кнопка «На главную» крупная.

Что важно для 5 лет: крупные цели касания (>=44px), минимум текста,
эмодзи-подсказки, отсутствие неожиданных переходов.

## Сценарий «подросток 12 лет» (режим 9+)

1. Переключить на «9+» (переключатель на главной).
2. Проверить, что открылись более сложные карточки (например, числа 11–20,
   слово «друг», «лиса», «зуб»).
3. Игра «Собери слово» — больше букв-дистракторов, таймер короче.
4. Игра «На скорость» — таймер идёт, при истечении времени ответ засчитывается
   как ошибка.
5. Проверить экраны «Профиль» и «Для родителей» (ссылки в подвале).

## Проверки доступности (все сценарии)

- Навигация с клавиатуры (Tab / Enter / Space) по всем кнопкам.
- Контраст текста WCAG AA (основной текст тёмный на светлом, проверено).
- `aria-label` у иконок-кнопок (динамик, звёзды, сердечки).
- Уменьшенная анимация (`prefers-reduced-motion`) — анимации отключаются.
- Модалка результата переводит фокус (скринридер её объявляет).

## Офлайн

1. Загрузить сайт, затем DevTools → Network → Offline, обновить страницу.
2. Убедиться, что приложение открывается и уроки работают (кроме озвучки,
   если аудио ещё не записано).
