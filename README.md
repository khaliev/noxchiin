# Нохчийн Мотт 🐺

**PWA-игра для изучения чеченского языка детьми и подростками от 5 лет.**

Учим алфавит, цифры, цвета и базовые слова в игровом формате уровня
Duolingo/Lingokids — специально для детей из чеченской диаспоры,
чтобы они не забыли язык своих близких.

## Что внутри

- Чеченский алфавит (49 букв) с транскрипцией и аудио
- Мини-игры: «слушай и выбирай», «собери слово», сопоставление и викторина
- Геймификация: сердечки, звёзды, XP, ежедневная серия (streak), маскот-волчонок
- Полная работа **офлайн** после первой загрузки (PWA)
- Контент в простых JSON-файлах — новые уроки можно добавлять без программирования

## Технологии

- [Astro](https://astro.build) — статическая генерация (SSG) и компоненты
- Vanilla JavaScript (ES2025+) — без тяжёлых фреймворков
- CSS-переменные (дизайн-система) — без препроцессоров
- Работает офлайн через Service Worker (Workbox — на Этапе 2)

## Быстрый старт

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
# 1. Установить зависимости
npm install

# 2. Запустить сервер разработки (http://localhost:4321)
npm run dev

# 3. Собрать продакшн-версию в папку /dist (включая Service Worker)
npm run build

# 4. Посмотреть собранный сайт локально
npm run preview
```

Другие команды:

```bash
npm run icons    # перегенерировать PNG-иконки PWA (волчонок)
npm run test     # запустить unit-тесты игровой логики
npm run check    # проверить код на ошибки
```

## Как добавить новый урок (для не-разработчика)

1. Открой файл `data/lessons/alphabet.json` в любом текстовом редакторе.
2. Скопируй один блок `{ ... }` внутри `"items": [...]` и измени значения:
   - `chechen` — буква/слово на чеченском
   - `russian` — перевод на русский
   - `transcription` — как произносится русскими буквами
   - `audio` — путь к звуковому файлу (например `/audio/alphabet/new.mp3`)
3. Сохрани файл. Проверь, что JSON валиден (нет лишних запятых).
4. Положи аудиофайл в `public/audio/alphabet/new.mp3`.

Подробнее о правилах данных — в `data/schema/lesson.schema.json`.

## Аудио

Каждая буква/слово озвучивается **носителем языка** (базовый TTS не умеет
правильно произносить чеченские абруптивные звуки `пӀ, тӀ, кӀ` и гортанную
смычку `Ӏ`). Аудиофайлы кладутся в `public/audio/<тема>/<id>.mp3`.

См. `audio/README.md` для инструкции по записи аудио.
