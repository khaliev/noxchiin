# Нохчийн Мотт 🐺

**PWA-игра для изучения чеченского языка детьми и подростками от 5 лет.**

Учим алфавит, цифры, цвета и базовые слова в игровом формате уровня
Duolingo/Lingokids — специально для детей из чеченской диаспоры,
чтобы они не забыли язык своих близких.

## Что внутри

- Чеченский алфавит (49 букв) с транскрипцией и аудио
- Мини-игры: «слушай и выбирай», «собери слово», сопоставление и викторина
- Геймификация: сердечки, звёзды, XP, ежедневная серия (streak), маскот-волчонок
- Полная работа **офлайн** после первой загрузки (PWA)
- Контент в простых JSON-файлах — новые уроки можно добавлять без программирования

## Технологии

- [Astro](https://astro.build) — статическая генерация (SSG) и компоненты
- Vanilla JavaScript (ES2025+) — без тяжёлых фреймворков
- CSS-переменные (дизайн-система) — без препроцессоров
- Работает офлайн через Service Worker (Workbox — на Этапе 2)

## Быстрый старт

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
# 1. Установить зависимости
npm install

# 2. Запустить сервер разработки (http://localhost:4321)
npm run dev

# 3. Собрать продакшн-версию в папку /dist (включая Service Worker)
npm run build

# 4. Посмотреть собранный сайт локально
npm run preview
```

Другие команды:

```bash
npm run icons    # перегенерировать PNG-иконки PWA (волчонок)
npm run test     # запустить unit-тесты игровой логики
npm run check    # проверить код на ошибки
```

## Как добавить новый урок (для не-разработчика)

Весь учебный контент — это простые текстовые файлы JSON в папке
`data/lessons/`. Чтобы добавить слово, букву или целую тему, **код менять не
нужно** — достаточно отредактировать JSON.

### Добавить слово в существующую тему

1. Открой нужный файл (например `data/lessons/food.json`) в любом редакторе
   (Блокнот, VS Code, TextEdit).
2. Найди блок `"items": [ ... ]`. Внутри — список карточек, каждая в `{ ... }`.
3. Скопируй одну карточку и вставь после последней (не забудь запятую между ними):
   ```json
   {
     "id": "food-egg",
     "type": "word",
     "chechen": "хӏоа",
     "russian": "яйцо",
     "transcription": "хIоа",
     "emoji": "🥚",
     "audio": "/audio/food/food-egg.mp3",
     "ageGroup": "all"
   }
   ```
4. Сохрани. Проверь, что JSON валиден (лишняя запятая = ошибка).
5. Положи аудиофайл в `public/audio/food/food-egg.mp3`.

### Создать новую тему

1. Скопируй любой файл (например `animals.json`) и назови по-новому, например
   `nature.json`.
2. Внутри поменяй `id` (например `"nature"`), `title` (название на русском и
   чеченском), `order` (номер по порядку — от него зависит разблокировка),
   `icon` (эмодзи) и список `items`.
3. Готово — тема появится на карте автоматически.

### Поля карточки

| Поле | Что значит | Пример |
|---|---|---|
| `id` | уникальный код (== имя аудиофайла) | `food-egg` |
| `type` | тип: `letter`/`word`/`number`/`color` | `word` |
| `chechen` | слово на чеченском | `хӏоа` |
| `russian` | перевод | `яйцо` |
| `transcription` | как произносится русскими буквами | `хIоа` |
| `emoji` | картинка-эмодзи (для слов) | `🥚` |
| `color` | цвет HEX (для темы «Цвета») | `#d32f2f` |
| `numeral` | цифра (для темы «Цифры») | `7` |
| `audio` | путь к звуку от корня сайта | `/audio/food/food-egg.mp3` |
| `ageGroup` | `all` / `5-8` / `9+` (сложность) | `all` |

Подробные правила — в `data/schema/lesson.schema.json`.

## Аудио

Каждая буква/слово озвучивается **носителем языка** (базовый TTS не умеет
правильно произносить чеченские абруптивные звуки `пӀ, тӀ, кӀ` и гортанную
смычку `Ӏ`). Аудиофайлы кладутся в `public/audio/<тема>/<id>.mp3`.

См. `audio/README.md` для инструкции по записи аудио.
