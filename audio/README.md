# Аудио-файлы «Нохчийн Мотт»

> ⚠️ **ВАЖНО**: обычный text-to-speech (TTS) **не умеет** правильно произносить
> специфичные чеченские звуки. Используй записи носителя языка.

## Куда класть файлы

Аудиофайлы лежат в `public/audio/` (это папка «от корня сайта», т.е. файл
`public/audio/alphabet/letter-a.mp3` доступен по адресу
`/audio/alphabet/letter-a.mp3` — именно такой путь прописан в JSON-карточках).

Структура:

```
public/audio/
├── alphabet/     # буквы алфавита: letter-a.mp3, letter-ae.mp3, ...
├── numbers/      # цифры (Этап 3)
├── colors/       # цвета (Этап 3)
└── words/        # слова по темам (Этап 3)
```

## Правила именования

Имя файла = `id` карточки из JSON + расширение `.mp3`.

Например, для карточки `"id": "letter-ae"` (буква «Аь») файл должен называться
`letter-ae.mp3`.

## Как записать аудио (приоритеты)

1. **Лучший вариант** — записать с носителем языка (родственник, учитель,
   волонтёр из диаспоры). Это самое надёжное качество произношения.
2. **Референс** — свериться с открытыми аудио-ресурсами носителей, чтобы
   понять правильное произношение:
   - Forvo (раздел чеченского) — forvo.com/languages/ce/
   - audiolang.info/chechenskij-alfavit — алфавит с аудио по буквам
   - nohchalla.com — аудиокурс чеченского языка
   - mylittlewordland.com/course — базовый курс с аудио
   - mp3-словарь «МИР1000» (mir2050.narod.ru)

   ⚠️ Перед использованием чужих файлов в публичном продукте **проверь лицензию
   и получи разрешение автора**. Иначе используй их только как эталон для
   собственной записи.

## Технические требования к файлам

- Формат: **MP3**, битрейт **96–128 kbps** (для голоса этого достаточно и это
  экономит вес приложения).
- Моно (не стерео) — голос, стерео не нужно.
- Каждая буква/слово — **отдельный файл** (не длинные дорожки), чтобы мини-игры
  могли проигрывать нужный звук.
- Очищай файл от пауз и шума в начале/конце (можно в Audacity, бесплатно).

## Плейсхолдеры

Сейчас в проекте файлов аудио нет — в JSON стоят пути-плейсхолдеры.
AudioPlayer-модуль (Этап 2) умеет показывать понятную подсказку, если файла
ещё нет, а не «молчать».
